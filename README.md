# BrickBreakerPong

A two-player brick-breaker/Pong prototype built with Pygame.

## Run it

Install Pygame:

```bash
python -m pip install pygame
```

Start the game:

```bash
python main.py
```

## Controls

- Player 1: `W` / `S`
- Player 2: Arrow `Up` / `Down`
- `Space`: pause/resume
- `R`: restart
- `Escape`: quit
